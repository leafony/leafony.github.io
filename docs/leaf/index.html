プロセッサ

Section titled “プロセッサ”

AP01 AVR MCU

プログラムを動かしてセンサの値を読み取り、他のリーフを制御できます。ATmega328Pを使用し、デジタル入出力・PWM出力・アナログ入力を備えています。

Basic Kit 2Basic Kit

AP03 STM32 MCU

センサの読み取りや他のリーフの制御を、32-bitのSTM32マイコンで実行できます。USB接続にはUSBリーフ、SWD接続にはShieldリーフを使用します。

Basic Kit 2

AP03B STM32

センサの読み取りや他のリーフの制御を実行できます。AP03の新設計版で、STM32L452REI6を搭載しています。

AP05 STM32N6

画像処理やエッジAIの評価を想定したMCUリーフです。STMicroelectronicsのSTM32N6シリーズを搭載しています。

通信

Section titled “通信”

AC02 BLE Sugar

MCUリーフと組み合わせて、Bluetooth LEでセンサデータなどを送受信できます。Silicon Labsの技適認証済みモジュールBGM11S22F256GA-V2を搭載しています。

Basic Kit 2Basic Kit

AC07 LoRa Mary

MCUリーフと組み合わせて、LoRa無線で対応する機器とデータを送受信できます。MurataのType ABZモジュールと、工事設計認証を受けたSTAF製チップアンテナを搭載しています。

ショップを見る — AC07 LoRa Mary ↗

AC08 LTE-M Mary

MCUリーフと組み合わせて、LTE-Mの携帯電話網でデータを送受信できます。利用にはAV06電源リーフ、対応するSIMと通信契約が必要です。MurataのType 1SCモジュールと認証済みチップアンテナを搭載しています。

ショップを見る — AC08 LTE-M Mary ↗

AC09 Cat-M1 TY

Cellular LPWA Cat-M1の携帯電話網を使ったデータ通信向けのリーフです。太陽誘電のWSCLxADAH2Zシリーズ、nanoSIMスロット、外部アンテナ用U.FLコネクタを備えています。

IO

Section titled “IO”

AI01 4-Sensors

温度・湿度・明るさを測定し、加速度から傾きや動きを検知できます。MCUリーフと組み合わせて、周囲の環境やリーフを取り付けた物の動きを調べられます。

Basic Kit 2Basic Kit

AI05 Env Sensors

温度・湿度・気圧・3軸加速度を測定できます。標準構成はBME280とLIS2DW12で、MCUリーフからI2Cで読み取ります。

電源

Section titled “電源”

AV01 CR2032

CR2032コイン電池から各リーフに3.3Vの電源を供給できます。MCUから電池電圧を読み取り、電源スイッチでオン・オフすることもできます。

Basic Kit 2Basic Kit

AV06 1.8V～5.5V

1.8V～5.5Vの電池から3.3V・最大1Aを供給できます。PHコネクタで電池を接続し、MCUから電池電圧を読み取れます。

ショップを見る — AV06 1.8V～5.5V ↗

AV05 Solar Charger

太陽電池を利用した電源供給・充電に対応する電源リーフです。

拡張

Extension Kit

Basic Kit 2Basic Kit

AX02B 29pin

外部回路を接続して試作や信号確認ができます。Leafony Busの29ピンを2.54mmピッチのスルーホールパッドへ引き出しています。

AX04 Spacer

ショップを見る — AX05B I Meas ↗

その他

Section titled “その他”

AZ01 USB

AVR MCU へのスケッチ書き込みやシリアルモニタを使用する場合に接続するリーフです。USB-UART変換ICとしてFTDI製FT232RQを搭載しています。USBのVBUS(5V)から降圧電源回路により3.3Vに変換し、各リーフにVBUSと3.3Vを供給します。 後継リーフは AZ01C USB-C です。AZ01CでAP01へ書き込む場合は、手動リセットが必要です。

Basic Kit 2Basic Kit

AZ01C USB-C

USB Type-Cでパソコンと接続し、シリアル通信と各リーフへの3.3V給電ができます。AP01へのプログラム書き込みには、手動リセットが必要です。
