手元のリーフはどうやって見分けるの？

リーフの見分け方

基板に印刷されている型番（品番）で見分けられます。まずは裏面を見てみてください。 多くのリーフでは、裏面に AZ01C や AI04A のような英数字が印刷されています。リーフによって印刷位置が異なるので、見つからなければ表面も確認します。

  1. 基板の上の文字を探します。 黒い部品の表面にも文字がありますが、そちらは部品自体の型番です。リーフの型番は基板に直接印刷されています。
  2. 末尾の文字まで読み取ります。 たとえば AZ01C なら、最後の C まで控えます。
  3. リーフ一覧から該当する資料を開きます。 型番に加えて、表裏の写真やUSB端子・画面などの形も、手元のリーフと見比べてください。
基板の印刷例リーフの役割確認する資料
AZ01CパソコンとUSB-CでつなぐAZ01C USB-C
AI04A文字や数値を画面に表示するAI04 LCD
AP01Aプログラムを動かすAP01 AVR MCU

重ねたリーフを取り外して確認する場合は、先にUSBケーブルを抜き、電池などの電源も外してください。

型番の最後のアルファベットも必要？

リーフの見分け方

はい。手順を選ぶときは、印刷されている型番を末尾まで確認してください。

資料の見出しでは AP01 や AI04 と短く書かれていても、実物には AP01A・AP01B・AI04A などと印刷されていることがあります。末尾が違うと、基板の仕様や操作手順が異なる場合があります。たとえば、AZ01 USBとAZ01C USB-CではUSB端子やAP01への書き込み時のリセット方法が異なります。

資料を開いたら、説明が手元の型番を対象にしているかも確認してください。

型番が見つからない・読めないときは？

リーフの見分け方

スマートフォンで基板の表と裏を撮影し、拡大してみてください。重ねたままで印刷が隠れているときは、購入したキットの製品ページにある構成リーフと、リーフ一覧の写真を見比べる方法もあります。

候補を絞るときは、読める文字・端子の種類・スイッチや部品の位置を、技術資料の表裏の写真と照合します。たとえばUSB-C端子ならAZ01C、文字を表示する画面ならAI04、CR2032用の電池ホルダならAV01が候補になります。外観の一部分だけで決めず、基板全体と末尾の文字も見比べてください。写真を撮るために取り外す場合も、先にすべての電源を外します。

電源が入らない

電源・組み立て

Leafonyの電源が入らない場合は、以下の項目をチェックしてください。

  • 電池の残量が十分にあるか。
  • ボタン電池の入れる向きは正しいか。
  • 電源スイッチがONになっているか。
  • コネクタが汚れていないか。汚れていたら、無水エタノールを含ませた紙製ウエスで軽く拭いてください。それでも改善しない場合は、コネクタを交換してください。詳しくは、こちら。
  • ネジの締めは問題ないか。緩みがあるならば、ネジを交互に締めてください。

接続・書き込み

書き込みに失敗する

接続・書き込み

IDEのエラー全文を確認し、使っているマイコンとUSBリーフに合う手順を開いてください。

  • AP01 / AP01B（AVR MCU）＋AZ01C（USB-C）：AZ01Cの書き込み手順で、ボード・ポート設定と手動リセットの操作を確認します。
  • ほかの構成：開発環境設定から、AP01（AVR）、AP02（ESP32）、AP03（STM32）と使用する開発ツールに合う手順を選びます。

LCDに文字が表示されない

画面・無線接続

AI04を使う場合は、LCDへの給電 → 初期化 → コントラストの順に確認します。

  1. サンプル一覧から、使用するMCUに対応するLCDサンプルを選びます。掲載サンプルのライブラリはtomozh氏のarduino_ST7032です。
  2. I2C I/O ExpanderでLCDへの給電を有効にします。lcd.begin()だけでは、リーフ側の電源スイッチは操作されません。
  3. サンプルの順序でLCDを初期化し、コントラストを設定して文字を表示します。

具体的な処理とアドレスはAI04の給電と初期化にあります。ST7032.hが見つからない場合は、ライブラリエラーの確認手順を参照してください。

BLEで接続できない・機器が見つからない

画面・無線接続

使っているキットと書き込み済みのプログラムに合うガイドで、対応する端末・ブラウザと接続方法を確認してください。

  • Basic Kit、またはBasic Kit 2のAVR MCUを使う出荷時デモ：Basic Kitスタートガイドで、Android・パソコン・iPhone / iPadなど、使用する端末の手順を確認します。
  • Basic Kit 2のSTM32 MCUを使う出荷時デモ：Basic Kit 2スタートガイドで、ビーコンの受信と接続、それぞれの使い方とブラウザの注意点を確認します。
  • サンプルや自作のプログラムを書き込んだ場合：サンプル一覧から使用した記事を開き、接続先の名前や受信側アプリなど、そのプログラムの手順を確認します。上の出荷時デモとは動作が異なる場合があります。

見つかった後の症状も、次のように切り分けられます。

  • 見つかるのに接続できない： STM32 Simple BLE Beaconは接続しない設定です。Beaconと接続型サンプルの違いを確認します。
  • 接続できるが値を読めない： 送信プログラムと受信アプリで、UUID・通知の設定・データ形式を照合します。BLEのデータ形式と受信処理に確認箇所をまとめています。

ESP32のWi-Fiにつながらない・デモ画面が開かない

画面・無線接続

ESP32 Wi-Fi Kit / Kit 2に入っているタッチセンサのデモは、次の順番で切り分けます。最初にできなくなった段階から確認してください。

段階確認すること
Leafony_ESP32-APが見つからない電源、電池の向き・残量、MCUにデモが入っているかを確認します。別のスケッチでは同じWi-Fiが出るとは限りません。
見つかるが接続できないスタートガイドのとおり、Leafony_ESP32-APを選び、パスワードpasswordを入力します。スケッチで変更した場合は変更後の値を使います。
接続したが画面が開かない端末の接続先がLeafonyのWi-Fiのままか確認します。アドレスバーへhttp://192.168.4.1をhttp://から入力してください。本デモはローカルの画面を表示するため、インターネット接続は不要です。「インターネットなし」でも接続を維持するか聞かれたら、Leafonyへの接続を維持します。

プログラムを書き換えた場合は、そのプログラムで指定したSSID・アドレスを使います。出荷時デモの手順で確認したい場合は、デモを書き戻す方法で、MCUに合うプログラムへ戻せます。

AC09のセルラー通信には、何ボルトの電源が必要ですか？

電源・組み立て Cat-M1 AC09AV06AV01

AC09 Cat-M1 TYは、Leafony Busの3.3V端子から給電して使います。

AC09のセルラー通信は、携帯電話のLTE網を使うIoT向けのCat-M1方式です。

モジュール単体の仕様とは分けて見ると、電源を選びやすくなります。

対象電源の仕様
AC09リーフLeafony Busの3.3V端子（1番ピン）から給電
太陽誘電WSCLxADAH2Zシリーズのモジュール単体メーカー公表の動作電圧範囲は2.3～4.2V

2.3～4.2Vはモジュール単体の値で、Leafony Busへ入力できる電圧の範囲とは異なります。AC09には、RF部や信号回路向けの電源回路と、UARTのレベル変換回路も搭載されています。

電池で使うならAV06がおすすめです

AC09を電池で使う場合は、AV06 1.8V〜5.5V 電源リーフと、乾電池などの外部電池を組み合わせる構成がおすすめです。 AV06は1.8〜5.5Vの入力を3.3Vに変換して各リーフへ給電します。この1.8〜5.5Vは、AV06へ接続する電池側の電圧範囲です。

Basic Kit 2に含まれるAV01＋CR2032コイン電池は、AC09のセルラー通信の電源には適していません。 同じ3.3Vを出せても、送信時に必要な電流を供給できるかは別の条件になります。Basic Kit 2へAC09を追加する場合は、電源構成も見直してください。

AC09の掲載サンプルでもAV06を使っています。AV06の仕様では最大出力電流は1Aですが、実際に供給できる電流は電池や入力電圧にもよります。使用する電池の仕様と、接続するリーフ全体の消費電流を合わせて確認すると安心です。AC09のピーク電流の実測値は、確認後に案内予定です。

外部のセンサーを接続できますか？

接続・書き込み I2CGrove AX02BAX06AI05

はい、接続できます。センサーの通信方式や電圧に合わせて、次のような接続方法を選べます。

接続方法向いている用途
AX02B 29-pinLeafony Busの29本の信号を2.54mmピッチのパッドへ取り出して配線する
AX06 Grove&5VGroveコネクタで、I2C・UART・アナログ・デジタル信号を接続する
AI05 Env SensorsのJ1外部の3.3V I2CセンサーをGND・3.3V・SDA・SCLへ接続する

組み合わせを選ぶときは、次の4点が手がかりになります。

  • 電源電圧と消費電流： センサーに合った電源を用意できるか。
  • 信号電圧： MCUとセンサーの信号レベルが合うか。5Vの電源を使うセンサーでも、信号電圧は別に確認します。AX02Bには電圧変換の機能がないため、条件に応じてレベル変換回路を組み合わせます。
  • ピンとI2Cアドレス： 他のリーフと競合しないか。たとえば、AI05の加速度センサーとAX06のI/Oエキスパンダはどちらも0x18を使います。
  • プログラム： 使用するMCU・開発環境に対応したドライバやライブラリがあるか。

Groveの場合も、コネクタの形に加えて電圧や信号の対応を見ておくと選びやすくなります。リーフの組み合わせ・電源の選び方に詳しい説明があります。

最初に試す順序

  1. センサーの仕様書で通信方式・電源・信号電圧を確認し、上の表から接続方法を選びます。I2Cの場合は、アドレスマップで既存のリーフとの重複も照合します。
  2. すべての電源を外してから接続します。まずはMCU・電源・必要な接続リーフと、外部センサー1台の構成で試します。
  3. 使用するMCUに対応したセンサーの最小読み取りサンプルを動かし、シリアル出力などで値を確認します。

C言語やC++でプログラムを作れます。 LeafonyのAP03 STM32 MCUでは、Arduino IDEまたはSTM32CubeIDEを使った開発を想定しています。

Arduinoで書くプログラムを「スケッチ」と呼びます。.inoファイルのスケッチは、C++をベースにしたプログラムとしてコンパイルされます。C言語で学ぶ変数・条件分岐・繰り返し・関数などの知識を活かせます。

  • setup()：起動時に一度実行する、センサーや通信の初期設定などを書きます。
  • loop()：その後に繰り返す、センサーの読み取りやデータ送信などを書きます。

初めての場合は、開発環境とライブラリ・ボード定義を設定し、サンプル一覧からSTM32向けのものを選んで、値や処理を少しずつ変えてみると進めやすくなります。

ST社のSTM32CubeIDEでは、C/C++での開発とデバッガを使った確認ができます。AP03の接続構成はデバッガの接続方法に掲載しています。ArduinoのスケッチをCubeIDEでそのまま開けるわけではないため、LeafonyのArduinoサンプルを試す場合は、そのサンプルが案内している環境から始めると進めやすくなります。

Pythonでも使えますか？

プログラム・動作 BLEUART AP01AP02AP03

リーフ本体のプログラムは、Arduino IDE、またはSTM32リーフではSTM32CubeIDEを使うC/C++での開発を想定しています。

Arduinoサンプルから始める場合は開発環境を、AP03でSTM32CubeIDEとデバッガを使う場合はデバッガの接続方法を参照してください。ArduinoのスケッチとCubeIDEのプロジェクトは設定やライブラリの組み込み方が異なるため、そのまま移せるとは限りません。

PythonはPC側で、Leafonyのデータを受信・保存・グラフ化・分析する用途に利用できます。 Leafony側のC/C++プログラムが送るデータに合わせて、PC側にPythonの受信プログラムを用意します。

接続方法Python側の選択肢と確認すること
USB経由のシリアル通信pySerialで受信できます。シリアル出力するプログラムを書き込み、ポート名・通信速度・改行などのデータ形式を合わせます。必要なUSB接続用リーフはMCUによって異なります。
BLEでの無線通信BleakでGATTの読み取りや通知の受信ができます。PCのBluetooth環境、使用中のサンプルの接続方式・UUID・データ形式を確認します。

USBで始めるなら、STM32の温湿度センサーサンプルがシリアル出力の例になります。このサンプルの通信速度は115200 bpsです。まずArduino IDEのシリアルモニタで値が出ることを確認し、モニタを閉じてからPython側で同じポートを開くと進めやすくなります。

BLEの場合は、データ形式とUUIDの確認方法を参考に、サンプルに合わせて受信コードを作成します。接続しないBeaconのデータは、GATT接続ではなくAdvertising dataをスキャンして読み取ります。

リーフ本体にPythonを書き込みたい場合は、MicroPythonなどの別の実行環境が必要です。 ESP32向けMicroPythonはありますが、対応チップであることだけでLeafonyの各リーフやセンサーがそのまま使えるとは限りません。使用ボードに合うファームウェア・ピン設定・センサー用ドライバーを確認します。現時点のLeafony Docsには、AP02・AP03での動作確認済みMicroPython導入手順は掲載していません。

センサーデータの分析が目的なら、まずはLeafony側を既存のArduinoサンプル、PC側をPythonにする構成から始められます。STM32で使う言語についても参照してください。
