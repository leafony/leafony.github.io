概要

Basic Kit / Basic Kit 2やESP32 Wi-Fi Kit / Kit 2と組み合わせて、人の接近を検知する、スピーカで音を鳴らす、マイクで周囲の音を読み取る、LCD（液晶ディスプレイ）に文字を表示するといった機能を追加できます。センサの値を文字やLEDで表示したり、人が近づいたら音を鳴らしたりするプログラムを試せます。

Extension Kitにはマイコンリーフが含まれていません。ソフトウェアを動かすには、Basic Kit / Basic Kit 2またはESP32 Wi-Fi Kit / Kit 2のマイコンリーフと組み合わせて使います。

内容物

9種類のリーフが入っています。写真や名前から、仕様・ピン配置などの技術資料を開けます。

AI02 SP&PIR

スピーカで音を鳴らし、人感センサで人の接近を検知します。
数量：1 生産終了

AI03 MIC&VR&LED

周囲の音やボリューム（可変抵抗）の設定を読み取り、LEDを点灯できます。
数量：1 生産終了

AI04 LCD

文字を表示し、スイッチで入力します。
数量：1 生産終了

AV03 AA BAT

単3電池から電源を供給します。
数量：1 生産終了

AX01 Shield

Arduino ShieldやSWD・ICSPコネクタに接続します。
数量：1
ショップを見る — AX01 Shield ↗

AX03 Leaf x2

リーフを横並びに接続します。
数量：1 生産終了

AX04 Spacer

リーフの間に挟み、間隔を広げます。
数量：1
ショップを見る — AX04 Spacer ↗

AX05 I Meas.

リーフに流れる電流を測定するときに使います。
数量：1 生産終了

AX06 Grove&5V

5Vで動作するGroveモジュールを接続します。
数量：1 生産終了
