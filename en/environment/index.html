Choose a development tool

If an example specifies a tool or project, start with that tool. Otherwise, choose the workflow that fits your goal.

  • Arduino IDE — Start with an Arduino sketch and try the sensor and communication examples.
  • PlatformIO — Work in VS Code and manage board settings and libraries for each project.
  • STM32CubeIDE — Configure STM32 peripherals and develop with ST's tools. Follow the CubeIDE examples and debugger requirements.

Using AP03B or AP05?

The setup guides above target AP01, AP02 and AP03. Check the documentation for your exact model before choosing its board definition or upload connection.

  • AP03B STM32 MCU — Check the pin assignments, power and programming connections. AP03 software settings are not automatically interchangeable.
  • AP05 STM32N6 — Start with the published design resources and development requirements for this model.
