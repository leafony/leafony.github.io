Microcontrollers

AP01

AVR MCU

Run programs to read sensors and control other leaves. Uses an ATmega328P with digital I/O, PWM outputs, and analog inputs.

Specifications and connections

AP03

STM32 MCU: Arduino-Compatible Microcontroller Leaf

Read sensors and control other leaves with a 32-bit STM32 microcontroller. Use a USB leaf for USB connections or a Shield leaf for SWD connections.

Specifications and connections

AP03B

STM32 MCU

Read sensors and control other leaves. A redesigned version of AP03, equipped with an STM32L452REI6.

Design reference available; AP03B upload instructions in preparation

Specifications and connections

AP05

STM32N6

An MCU leaf intended for evaluating image processing and edge AI. Uses an STMicroelectronics STM32N6-series microcontroller.

Specifications and connections

AP02

Discontinued

ESP32 MCU

Run programs and send or receive data over Wi-Fi or Bluetooth LE. Uses an ESP32-WROOM-32 with Japanese radio certification, and supports uploading sketches over USB.

Specifications and connections

Connectivity

AC02

BLE Sugar

Combine with an MCU leaf to send and receive sensor data and other information over Bluetooth LE. Uses a Silicon Labs BGM11S22F256GA-V2 module with Japanese radio certification.

Specifications and connections

AC07

LoRa Mary

Combine with an MCU leaf to exchange data with compatible devices over LoRa radio. Uses a Murata Type ABZ module and a STAF chip antenna covered by Japanese radio design certification.

Specifications and connections

AC08

LTE-M Mary

Combine with an MCU leaf to send and receive data using Cat-M1, an IoT cellular communication technology that runs on mobile operators' LTE networks. Requires an AV06 power leaf, a compatible SIM, and a mobile service contract. Uses a Murata Type 1SC module and a certified chip antenna.

Specifications and connections

AC09

Cat-M1 TY

A leaf for data communication over Cellular LPWA Cat-M1 networks. Includes a Taiyo Yuden WSCLxADAH2Z-series module, a nanoSIM slot, and a U.FL connector for an external antenna.

Specifications and connections

AC03

Discontinued

LoRa Easy

Send and receive data over LoRa radio. This leaf is discontinued. Its successor is AC07 LoRa Mary , which changes the MCU interface from UART to SPI.

Specifications and connections

AC04

Discontinued

LTE-M King M

Send and receive data using cellular communication. Requires AC05, a compatible SIM, and a mobile service contract. This leaf is discontinued. The successor cellular configuration uses AC08 LTE-M Mary and the AV06 power leaf.

Specifications and connections (Japanese)

AC05

Discontinued

LTE-M King S

Combine with LTE-M King M to supply power, upload programs to the MCU, and read battery voltage. This leaf is discontinued. For a new cellular configuration, see AC08 LTE-M Mary and the AV06 power leaf.

Specifications and connections (Japanese)

AC06

Discontinued

Wi-Fi Mary

Combine with an STM32 MCU to send and receive data over Wi-Fi. AVR MCU is not supported. This leaf is discontinued.

Specifications and connections (Japanese)

AI01

4-Sensors: Temperature, Humidity, Light and Acceleration

Measure temperature, humidity, and light, and use acceleration to detect tilt or movement. Combine with an MCU leaf to monitor the surrounding environment or the movement of an attached object.

Specifications and connections

AI05

Env Sensors

Measure temperature, humidity, pressure, and 3-axis acceleration. The standard configuration uses a BME280 and LIS2DW12, read over I2C by an MCU leaf.

Connections and more

AZ01

USB

Connect this leaf to upload sketches to an AVR MCU or use the serial monitor. It uses an FTDI FT232RQ USB-to-UART converter. A step-down circuit converts USB VBUS (5V) to 3.3V, supplying both VBUS and 3.3V to the leaves. The successor is AZ01C USB-C . Uploading to AP01 through AZ01C requires a manual reset.

Specifications and connections

AZ01C

USB-C

Connect to a computer through USB Type-C for serial communication and 3.3V power to the leaves. Uploading a program to AP01 requires a manual reset.

Specifications and connections

AZ61

Connector

Electrically connect stacked leaves. Place ACR (anisotropic conductive rubber) between the leaves and compress it with screws to make contact.

Specifications and connections

AZ62

Connector Cover

The Connector Cover protects the ACR (anisotropic conductive rubber) from dirt.

Specifications and connections

AZ63

Nut Plate

Specifications and connections
