Run your kit What is Leafony?

Basic Kit 2

Measure temperature, humidity, light, and acceleration, then send the readings over BLE. Build your first compact sensor device with Basic Kit 2.

The kit includes AVR and STM32 processor leaves. Start with the AVR demo in the assembled kit; no development tools are needed. Try STM32 after the first demo works.
