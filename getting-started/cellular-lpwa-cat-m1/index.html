Cellular LPWA Cat-M1 Kitは、センサーデータを携帯電話網から直接クラウドへ送れる、小型・省電力の開発キットです。Wi-Fi環境を用意せずに、離れた場所の温度や湿度を記録できます。

1. キットの内容物

リーフは、それぞれ袋に入った状態で届きます。まずは、次のリーフと付属品がそろっていることを確認してください。

リーフ

リーフ 役割
AC09 Cat-M1 TY 携帯電話網を使ったCellular LPWA Cat-M1通信を行います。
AX04 Spacer リーフの間に挟み、間隔を広げます。
AI05 Env Sensors 温度・湿度・気圧・3軸加速度を測定します。標準構成はBME280とLIS2DW12です。
AP03B STM32 MCU プログラムを動かし、センサの読み取りや通信リーフの制御を行います。AP03の新設計バージョンです。
AZ01C USB-C USB Type-Cでパソコンと接続し、シリアル通信や3.3V給電に使います。AP03Bへの書き込みには、対応プログラムが指定する接続・設定を確認してください。
AV06 1.8V～5.5V 電池から各リーフへ3.3Vの電源を供給します。電池ボックスはPHコネクターで接続します。
AX02B 29-pin Leafony Busの29ピンを2.54mmピッチのスルーホールパッドに引き出し、外部回路の試作や信号の確認に使います。

付属品

付属品 用途
AZ63 Nut Plate リーフをネジで固定するときに使います。
1NCE SIM（nanoSIM対応） AC09のセルラー通信に使用します。利用開始前にSIMの利用状態と通信設定を確認してください。
M2×18mmネジ 積み重ねたリーフを固定します。
PHコネクター付き単3形電池2本用ボックス AV06に接続して電池から給電します。

2. キットのゴール

サンプルプログラムを動かして、キットで測った温度と湿度を、Google スプレッドシートに10分ごとに記録することが、このガイドのゴールです。

データは、次のように届きます。

AI05で温度・湿度を測る → AC09で携帯電話網へ送る → Google スプレッドシートに記録

スプレッドシートには、受信日時・温度・湿度が1行ずつ記録されます。記録したデータは、あとからグラフにして変化を見ることもできます。

3. 準備するもの

キットのほかに、次のものを用意してください。

用意するもの用途
インターネットに接続できるパソコン開発ツールのインストール、プログラムの書き込み、スプレッドシートの設定に使います。
データ通信対応のUSB-Cケーブルパソコンとキット付属のAZ01C USB-Cリーフをつなぎます。充電専用ケーブルは使えません。
単3形乾電池2本最後に電池駆動を試すとき、付属の電池ボックスに入れます。
ネジに合うドライバーリーフを固定するネジを締めます。
Googleアカウントデータを保存するGoogle スプレッドシートを作ります。

パソコンで、次の準備を済ませてください。

  1. 開発環境の設定に沿って、VS Code・PlatformIO・STM32CubeProgrammerをインストールします。
  2. 付属の1NCE SIMが利用できる状態であることと、指定された**APN（携帯電話網への接続設定）**を確認します。利用開始方法はキットの販売案内を参照してください。
  3. Google スプレッドシートの準備に沿って、保存先とデータを受け取るApps Scriptを設定します。発行された送信先URLと、自分で設定した認証用トークンを控えます。

4. キットの組み立て

USBケーブルと電池を外した状態で作業します。

組み立てを動画で見る（SIMの取り付けから）
  1. 付属の1NCE SIMをnanoSIMサイズにし、AC09のSIMホルダーに装着します。カードの切り欠きとホルダーの形状を確認してください。
  2. リーフのバス接点とネジ穴の位置を合わせ、下の順に重ねます。
  3. コネクタの向きと、部品同士が接触していないことを確認し、付属のM2×18mmネジとAZ63 ナットプレートで固定します。

組み上がった状態の上から下の順は、次のとおりです。

位置リーフ
1（最上段）AI05 Env Sensorsリーフ
2AZ01C USB-Cリーフ
3AP03B STM32リーフ
4AX04 スペーサーリーフ
5AC09 Cat-M1リーフ
6（最下段）AV06 電源リーフ

スペーサーリーフは、STM32リーフとCat-M1リーフの間に入れます。同梱のAX02B 29-pinリーフは外部回路をつなぐときに使うため、今回は重ねません。

重ね方やネジの締め方は、組み立て・組み替えの基本も参考にしてください。

5. サンプルコードの書き込み

サンプルを開いて設定する

  1. AC09の開発リポジトリからサンプルを取得し、VS Codeで**platformio/google_sheetsフォルダー**を開きます。リポジトリにアクセスできない場合は、ソースコードの入手方法を確認してください。
  2. include/config.example.hをコピーして、同じフォルダーに**config.local.h**を作ります。
  3. config.local.hの次の項目を、自分の設定に書き換えます。
設定名設定する値
GAS_URL準備したApps ScriptのURL。末尾が/execのものを使います。
GAS_API_TOKENApps Scriptに登録した認証用トークンと同じ文字列。
SIM_PROVIDER付属の1NCE SIMを使うので1。
ONE_NCE_APN付属SIMに指定されたAPN。
SEND_INTERVAL_MS600000UL（10分）。

AP03Bに書き込む

電池はまだ接続せず、AZ01C USB-CリーフとパソコンをUSBケーブルでつなぎます。

  1. platformio.iniのupload_portとupload_commandを、パソコンの接続ポートとSTM32CubeProgrammerの場所に合わせます。OS別の設定例を参考にし、このキットでは**leafony_ap03b**環境を使ってください。

  2. VS CodeのPlatformIOターミナルを開き、ビルドします。

    pio run -e leafony_ap03b

  3. AP03BのPGスイッチをProgram側にし、RSTボタンを押します。その後、次のコマンドで書き込みます。

    pio run -e leafony_ap03b -t upload

  4. 書き込みが成功したら、PGスイッチをRun側に戻します。

スイッチの位置はAP03Bの資料で確認できます。

6. 動作確認

  1. USBケーブルをつないだまま、次のコマンドでシリアルモニターを開きます。

    pio device monitor -e leafony_ap03b -b 115200

  2. AP03BのRSTボタンを押してプログラムを起動します。携帯電話網への接続と時刻の取得が終わるまで待ちます。

  3. シリアルモニターに**Saved to Google Sheets**と表示されたら、Google スプレッドシートを開きます。

  4. temperatureシートに受信日時・温度・湿度の行が追加されていれば成功です。 そのまま動かしておくと、10分ごとに新しい測定値が追加されます。

受信日時はUTCで記録されます。日本時間で読むときは9時間を加えてください。

行が追加されない場合は、シリアルログの見方とトラブルシューティングで、表示されたメッセージに対応する設定を確認してください。

7. 次のステップ

パソコンから離して電池で動かす

  1. USBケーブルを外し、AV06の電源スイッチをOFFにします。
  2. 付属の電池ボックスに単3形乾電池を2本入れ、プラス・マイナスの向きを確認します。電池ボックスのPHコネクターをAV06につなぎます。
  3. AP03BのPGスイッチがRun側であることを確認し、AV06の電源スイッチをONにします。
  4. スプレッドシートに新しい行が追加されることを確認します。

電池で動かすときはUSBケーブルを外して使ってください。電源スイッチとコネクターの位置はAV06の資料を参照してください。

記録したデータやプログラムを活用する

  • 温湿度の変化をグラフにする：スプレッドシートの日時・温度・湿度の列を選び、「挿入」→「グラフ」で表示できます。
  • 記録の間隔を変える：SEND_INTERVAL_MSを変更して、もう一度書き込みます。設定値の範囲はサンプルの設定項目を確認してください。
  • 電池の消費を抑える工夫を学ぶ：省電力設計で、通信間隔やスリープの考え方を紹介しています。
