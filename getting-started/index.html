お持ちのキットを選ぶ

Basic Kit / Basic Kit 2とESP32 Wi-Fi Kit / Kit 2には、デモ用のプログラムが書き込まれています。出荷時のプログラムがあれば、開発環境を構築する前に動作を確認できます。

Basic Kit 2

AVRとSTM32、2種類のマイコンリーフが入っています。出荷時はAVRが組み込まれているので、最初はBasic Kitの手順で試してください。

キットの内容を確認する → ショップを見る ↗

  1. まずは、BLEでセンサの値を見る

    CR2032コイン電池と対応するスマートフォンやパソコンを用意し、Basic Kitのガイドに沿って接続します。

    出荷時のAVRデモから始める →

  2. メモリや処理の余裕が必要になったら

    最初はAVRのまま使えます。必要に応じて付属のSTM32に交換し、センサデータの記録やBLEのデモを試せます。

    STM32のデモを試す（任意） →

その他のキットをお持ちの方

  • Cellular LPWA Cat-M1 Kit太陽誘電製モジュール搭載のAC09を使うキットです。AP03B＋AI05の準備物と参考サンプルとの差分を確認できます。専用の動作手順は準備中です。 →
  • Basic Kit出荷時のAVRプログラムで、BLEを使ってセンサの値を表示します。 →
  • ESP32 Wi-Fi Kit / Kit 2単4電池3本を用意し、キットのWi-Fiに接続してブラウザでタッチセンサの値を表示します。 →

必要なもの・対応する端末やブラウザは、各ガイドで確認してください。デモを書き換え済みの場合は、開発環境設定とサンプルアプリへ進んでください。
